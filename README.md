# Каждый ребёнок имеет право · Беларусь

Образовательный сайт ко Всемирному дню ребёнка (20 ноября): права детей из
Конвенции ООН о правах ребёнка и семейного законодательства Беларуси —
простыми словами, на русском и белорусском языках.

## Возможности

- 16 карточек прав по 4 темам с фильтром по категориям
- Расширенная информация по каждой статье — в модальном окне
- Викторина из 10 вопросов с пояснениями
- Переключение языка `RU` / `БЕ` (запоминается в `localStorage`)
- Раздел «Помощь» с детской телефонной линией и экстренными службами

## Запуск локально

```bash
npm install
npm run dev
```

Сборка и проверка: `npm run build`, `npm run lint`.

## Деплой на GitHub Pages

Сборка использует относительные пути (`base: './'`), поэтому сайт работает
и в корне пользовательских страниц, и как project site в подпапке.

1. Создайте публичный репозиторий на GitHub и загрузите туда содержимое
   этой папки (корень репозитория — файлы приложения).
2. В репозитории откройте **Settings → Pages** и в поле
   **Source / Deploy from a branch** выберите **GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` сам соберёт приложение и
   опубликует его при пуше в ветку `main` (или `master`).
4. Готовый сайт откроется по адресу
   `https://ldima8286-cmd.github.io/Sait-prava-rebenka/`.

Ручной запуск деплоя: **Actions → Deploy to GitHub Pages → Run workflow**.
